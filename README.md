# MQTT Kafka connector

## Обзор проекта

Данный проект представляет собой коннектор на основе Python, соединяющий брокера MQTT и кластер Kafka. Основная задача приложения заключается в подписке на заданные темы MQTT, обработке входящих сообщений и публикации их в соответствующие темы Kafka.

Коннектор построен с использованием современных асинхронных библиотек Python:

-   `aiomqtt` для обработки коммуникаций MQTT.
-   `aiokafka` для взаимодействия с кластером Kafka.
-   `fastavro` и реестр схем для десериализации сообщений, закодированных в формате Avro.
-   `aioprometheus` для экспонирования метрик.

Настройка осуществляется посредством переменных окружения, которые могут загружаться из файла `.env`, как определено в файле `src/mqtt_kafka_connector/conf.py`. Точка входа основного приложения находится в файле `src/mqtt_kafka_connector/connector/main.py`.

Приложение предназначено для запуска в контейнеризированной среде обслуживания, при этом предоставляются файлы `Dockerfile` и `docker-compose.yml` для сборки и запуска коннектора.

## Сборка и запуск

### Зависимости

Зависимости проекта управляются с помощью инструмента `uv` и определены в файле `pyproject.toml`.

### Локальная разработка

-   **Настройка переменных окружения:**

    ```shell
    $ cp .env.example .env
    ```

    После чего внесите изменения в файл `.env`

-   **Запуск тестов:**

    ```shell
    make test
    ```

-   **Запуск приложения:**

    ```shell
    make run
    ```

    Альтернативно, после установки, можно воспользоваться скриптом, определенным в файле `pyproject.toml`:

    ```shell
    mkc
    ```

### Docker

-   **Сборка образа Docker:**

    ```shell
    docker build --no-cache -t piklema/mqtt-kafka-connector:latest .
    ```

-   **Запуск с Docker Compose:**
    Файл `docker-compose.yml` настроен для запуска сервиса коннектора.

## Конвенции разработки

-   **Проверка стиля и форматирование:** Проект использует инструмент `ruff` для проверки стиля и форматирования кода.

    -   `make lint`: Проверка наличия проблем со стилем.
    -   `make format`: Автоматическое форматирование кода.

-   **Тестирование:** Тесты расположены в директории `tests/` и написаны с использованием фреймворка `pytest`.

-   **Асинхронный код:** Весь код базы является асинхронным, используя возможности библиотеки `asyncio`.

-   **Настройки конфигурации:** Вся конфигурация управляется через переменные окружения, как определено в файле `src/mqtt_kafka_connector/conf.py`. Предоставлен файл шаблона `.env.example`.

-   **Контекстные переменные:** Приложение использует контекстные переменные (`src/mqtt_kafka_connector/context_vars.py`), чтобы управлять специфичными для запросов данными, такими как `device_id` и `message_uuid`, среди асинхронных задач.

### How to run

Rename `.env.example` to `.env` and changes values

### Run unittest

```shell
$ pip install -e ".[develop]"
$ make test
```

### Run script

```shell
$ mqtt_kafka_connector
```
